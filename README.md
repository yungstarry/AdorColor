# PaletteLab

PaletteLab is a browser-based color palette workspace for exploring, creating, completing, and previewing palettes.

## Run locally

**Prerequisite:** Node.js

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local URL printed by the server (by default, `http://localhost:3000`).

## Build

Run `npm run build` to create a production build in `dist`.
